# Reumatologia — roteiro do exame físico (texto do autor, 24/11/2026)

Como funciona na tela (autor, 24/11/2026):
- Só os cabeçalhos (1. a 5.) aparecem; clicar abre as opções daquela parte.
- Começa por GALS: abre, marca a opção (ou opções, quando múltipla escolha) e fecha; segue para a próxima.
- Usar as abreviações (GALS, IPAM, ADM, MCFs, IFPs, IFDs, MTFs, IFs, ATM, D/E), não o nome completo.
- Depois do item 5: um editor de texto para observações e informação a mais.
- Cada parte termina com o botão "Pronto ›": fecha, mostra o resumo numa linha e abre a próxima. O médico pode
  voltar em qualquer parte e mudar; só é definitivo quando salva o exame (24/11).
- Manobra marcada = manobra positiva. Não marcada não entra no prontuário (não feita ≠ negativa) (24/11).
- 4. Padrão: tudo marcado pelo médico; o app não sugere nada a partir do mapa (24/11).
- Ordem na tela (igual à derma): "Inserir prints, arquivos, laudos" · quadro de fotos · 1–5 · Observações.
  A IA lê os exames/laudos enviados e as fotos e escreve um resumo organizado (Laboratório · Imagem · Fotos),
  tracejado, logo abaixo do quadro de fotos; o médico confirma, corrige ou apaga. Valor não achado no laudo =
  "não encontrado no laudo", nunca inventado (24/11).

## 1. Triagem Inicial (GALS)
- Marcha: ( ) Normal | ( ) Claudicante | ( ) Assimétrica
- Braços (ombros/cotovelos/mãos): ( ) Normal | ( ) Alterado
- Pernas (quadris/joelhos/pés): ( ) Normal | ( ) Alterado
- Coluna (alinhamento/flexão): ( ) Normal | ( ) Alterada

## 2. Mapa de Articulações Acometidas (múltipla escolha; D = direita, E = esquerda)
Membros superiores: Ombro D/E · Cotovelo D/E · Punho D/E · MCFs D/E · IFPs D/E · IFDs D/E
Membros inferiores: Quadril D/E · Joelho D/E · Tornozelo D/E · Mediopé/Tarso D/E · MTFs D/E · IFs (pés) D/E
Esqueleto axial e outras: ATM D/E · Esternoclavicular/Acromioclavicular D/E · Coluna cervical (Sim) · Coluna torácica (Sim) · Coluna lombar (Sim) · Sacroilíacas D/E

## 3. Exame Articular Dirigido (IPAM)
Inspeção: ( ) Edema articular · ( ) Eritema/rubor · ( ) Deformidade (desvio ulnar, pescoço de cisne, botoeira, genu varo/valgo) · ( ) Atrofia muscular adjacente
Palpação: ( ) Calor local · ( ) Dor à palpação da linha articular · ( ) Espessamento sinovial (consistência borrachoide) · ( ) Derrame articular positivo · ( ) Dor em enteses/bursas
ADM: ( ) Ativa preservada | ( ) Ativa limitada por dor/fraqueza · ( ) Passiva preservada | ( ) Passiva limitada (bloqueio mecânico/contratura) · ( ) Crepitação palpável/audível
Manobras específicas realizadas:
- Mão/Punho: ( ) Phalen | ( ) Tinel | ( ) Finkelstein | ( ) Squeeze test (MCF/MTF)
- Ombro: ( ) Neer | ( ) Hawkins | ( ) Jobe | ( ) Patte
- Joelho: ( ) Tecla/Rechaço | ( ) Gaveta ant/post | ( ) Lachman | ( ) McMurray
- Coluna/Sacroilíaca: ( ) Schober | ( ) Patrick (FABERE) | ( ) Gaenslen | ( ) Lasègue

## 4. Classificação do Padrão
- Número: ( ) Monoarticular (1) | ( ) Oligoarticular (2–4) | ( ) Poliarticular (≥ 5)
- Simetria: ( ) Simétrico | ( ) Assimétrico
- Localização: ( ) Periférico | ( ) Axial | ( ) Misto
- Natureza: ( ) Inflamatório | ( ) Mecânico | ( ) Difuso/Nociplástico

## 5. Exame Extra-Articular
( ) Placas psoriásicas/pitting ungueal · ( ) Eritema malar/fotossensibilidade · ( ) Fenômeno de Raynaud/esclerodactilia · ( ) Úlceras orais ou nasais · ( ) Olho seco/hiperemia ocular · ( ) Nódulos subcutâneos/tofos gotosos
